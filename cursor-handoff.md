## Context (Claude Code: read this first)

We're finishing a **reveal.js talk deck** (`index.html`, generated by Claude Design) for a
45-minute live session on vibe coding for admissions teams. The deck is scaffolding for
live demos. Two slides embed real dashboards we'll build here from sanitized data.

**Target structure**
```
vibe-coding-talk/
  index.html              # reveal.js deck (from Claude Design)
  assets/pomfret-crest.png
  demos/
    funnel.html           # dashboard from the xlsx
    lost-to.html          # dashboard from the csv
    data/funnel-data.js   # baked aggregates only
    data/lost-to-data.js  # baked aggregates only
  data-source/            # raw sanitized files — NEVER served/loaded at runtime
    Admission_info_for_GBS_June_1.xlsx
    Not_Enrolling.csv
```

**Hard rules**
- Demos load **only pre-computed aggregates** baked into `*-data.js`. Never read the raw
  files at runtime, never render row-level data. (This is also the talk's privacy point.)
- Everything must run **offline from `file://`** — no backend, no live fetch of the
  spreadsheets. CDN scripts are fine.

**Design tokens (match the deck exactly)**
- navy `#0F2A4A` · gold `#C2A14D` · cream `#F6F2E9` · ink `#14181F`
- code panels `#0D1117`
- fonts: JetBrains Mono (headers/labels/code), Inter (body), a serif (Cormorant/Playfair) for big titles
